# homebrew-tap

Kevin Gallaccio's [Homebrew](https://brew.sh) tap.

## freebox-cli — pilotez votre Freebox depuis le terminal

```sh
brew install kevingallaccio/tap/freebox-cli
```

Installs the `fbx` command: interactive app, full CLI, and MCP server for
the Freebox Ultra. See [KevinGallaccio/freebox-cli](https://github.com/KevinGallaccio/freebox-cli).

`Formula/freebox-cli.rb` is autogenerated by the
[freebox-cli release workflow](https://github.com/KevinGallaccio/freebox-cli/blob/main/.github/workflows/release.yml)
on every tagged release — don't edit it by hand.
